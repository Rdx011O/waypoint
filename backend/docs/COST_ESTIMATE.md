# WAYPOINT Shipper Cost Estimate & Currency Conversion Contract

This document specifies the output contract, data models, rounding invariants, and architectural guidelines for the WAYPOINT **Shipper Cost Estimate** module.

---

## 1. Core Architectural Distinction

> **Voyage Cost vs. Shipper Charge**
> - **Voyage Cost (Internal Basis):** Represents the carrier's operating cost to navigate the vessel from origin to destination (fuel consumption, ship charter/daily operating expenses, vessel canal fees). Computed internally by `routeService` and `optimizer`.
> - **Shipper Charge (Shipper-Facing):** Represents the estimated commercial billing payable by the shipper. Built modularly from tariff schedules, port tariffs, demurrage allowances, and optional surcharges.
>
> **Notice:** The route with the lowest voyage operating cost for the carrier is **not necessarily** the cheapest route for the shipper (e.g., corridors with heavy canal tolls or port dues may reverse cost advantages).

## 3. Field Specifications & Integrity Rules

### 3.1 Line Item Status & Missing Data Rules
- `estimated`: Tariff/model data is present and factored into the total.
- `not_available`: Data is unlisted in configured tables (e.g., an unlisted port or unlisted canal toll). The amount is `null`, **never 0**.
- `not_estimated`: Data has not been provided (e.g., no hazard/delay input from Member 4). The amount is `null`, **never 0**.
- **Transparency Guarantee:** Any line item not estimated is appended to `total.excludes` and documented with a user-facing explanation in `notAvailable`.

### 3.2 Displayed Sum Invariant (Rounding Guarantee)
- In the presentation layer, each line item amount is converted from USD to the selected currency and rounded using `Intl.NumberFormat` decimal rules (e.g., 0 decimals for `JPY`, 2 decimals for `EUR`/`USD`/`GBP`/`INR`/`AED`/`SGD`/`CNY`).
- `total.amountSelected` is calculated as the **exact sum of all rounded estimated line items**.
- **Mathematical guarantee:** A shipper will never see displayed line items that do not add up to the displayed total.

### 3.3 Dynamic Summary Generator
The `summary` field is constructed dynamically from numeric amounts:
- Format: `"Estimated total <Total>: freight <Freight>, port <Port>, delay allowance <Delay>. <Exclusions>."`
- Example with exclusions: `"Estimated total €3,643.47: freight €3,288.01, port €355.46. Destination port charges and Delay allowance not included."`

## 4. Currency Engine & Provider Abstraction

- **Base Currency:** `USD` for all internal arithmetic and storage.
- **Provider Interface:** `getRates(base, symbols, options)` wraps third-party FX providers.
- **Primary Live Provider:** Frankfurter API (European Central Bank reference mid-market rates).
- **Secondary Provider / Fallback:** Open Exchange Rates for non-ECB currencies (such as `AED`).
- **Resilience Hierarchy:**
  1. `live`: Fresh live probe within cache TTL.
  2. `cached`: In-memory cache when network call times out or fails (default TTL: 1 hour).
  3. `fallback`: Bundled `data/fallback_rates.json` if network is completely offline.
- **Commercial Spread:** Reference rates are mid-market. An optional `conversionSpread` (e.g., `0.02` for 2%) can be applied, which generates a visible `conversion_spread` line item.

## 5. Multi-Route Comparison API (`compareCostsAcrossRoutes`)

Enables Member 1's UI to display route cards with both carrier voyage cost and shipper billing:

```javascript
const { compareCostsAcrossRoutes } = require("./services/shipperCostService");

const comparison = await compareCostsAcrossRoutes(candidateRoutes, shipment, "EUR");
// comparison.cheapestShipperRouteId
// comparison.cheapestVoyageRouteId
// comparison.cheapestShipperDiffersFromVoyageCost (boolean)
```

## 6. Supported Inputs & Error Codes

### Supported Units
- `TEU` (Twenty-foot Equivalent Unit)
- `FEU` (Forty-foot Equivalent Unit)
- `tonne` (Metric ton)
- `cbm` (Cubic meter)

### Typed Error Codes
| Error Code | Throw Condition |
| :--- | :--- |
| `INVALID_QUANTITY` | Quantity is missing, non-numeric, 0, or negative |
| `UNKNOWN_UNIT` | Unit is not in `['TEU', 'FEU', 'tonne', 'cbm']` |
| `UNSUPPORTED_CURRENCY` | Currency is not in supported currency list |
| `RATE_UNAVAILABLE` | FX rate missing from provider, cache, and fallback |
| `FILE_PARSE_ERROR` | CSV/JSON charges file format or column error |
| `INVALID_ROUTE` | Route object missing or malformed |
| `INVALID_DELAY_DAYS` | Delay days is negative or non-finite |
